# 74HCT245D,652

Nexperia 8-bit bidirectional non-inverting bus transceiver, 3-state, TTL inputs.
Added as a distinct component in Dlib.SchLib; existing 74HC245D is unchanged.
Display comment: 74HCT245D. Ordering part number: 74HCT245D,652.

Pinout (D package): DIR=1; A0..A7=2..9; GND=10; B7..B0=11..18;
active-low output enable nOE=19; VCC=20. A/B pins are bidirectional;
DIR/nOE inputs; VCC/GND power. DIR HIGH selects A to B, LOW selects B to A;
nOE HIGH disables both output banks. Recommended supply: 4.5-5.5 V.

Symbol groups matching A/B channels, with separated control and supply rows.
Body SO20 / SOIC-20 wide / SOT163-1: 12.8 x 7.5 mm, 1.27 mm pitch.
Reuses existing SOIC-20_L12.8-W7.5-P1.27-LS10.3-TL footprint and embedded
74HC244D--3DModel-STEP-56544.STEP (same wide SO20 package geometry).
Existing 3D file origin is not manufacturer-verified; model is used for package
visualization. In its Altium orientation, dimensions are 10.3 x 12.8 x 2.5 mm.
The entire PcbLib remains unchanged. No external STEP path is required.
